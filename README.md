# Sausage Sizzle MY

Custom one-page website concept for Sausage Sizzle TTDI.

## Included
- Custom retro deli / food-truck visual direction
- Featured Sizzlin' Streaky hero
- Responsive catalogue
- Cart-style preorder flow
- WhatsApp checkout
- Catering and TTDI location sections
- Mobile responsive layout
